# Experimental

This directory holds early Smithy prototypes that are maintained in awesome-smithy while they take shape. Each project
has its own README with build instructions. Their output, settings, and names can change or be removed at any time, so
do not depend on them in production.

* [smithy-api-explorer](smithy-api-explorer): a Smithy build plugin that renders a service model as a self-contained,
  interactive HTML API reference.
